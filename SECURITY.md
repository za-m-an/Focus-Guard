## Reporting a Vulnerability

The FocusGuard project takes the security and privacy of home network deployments seriously.

If you believe you have discovered a security vulnerability or potential bypass loophole in FocusGuard:

1. **Do not disclose it publicly** in issues, discussions, or forums until it has been investigated and patched.
2. Please submit an advisory or contact the maintainer via GitHub Security Advisories or email:
   - Maintainer: `kamruzzaman467467@gmail.com`
3. Please include:
   - A description of the issue.
   - Steps to reproduce or proof-of-concept configuration.
   - Observed vs. expected behavior.
   - Network topology details (DietPi version, gateway mode vs. standard DNS mode, IPv4/IPv6).

We aim to acknowledge reports within 48 hours and provide patches promptly.
